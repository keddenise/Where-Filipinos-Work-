# Where-Filipinos-Work-
Interactive bump chart of Philippine employment by industry, 2012-2025. Built with D3.js using PSA Labor Force Survey data.

Topics:
d3js data-visualization bump-chart philippines labor-force-survey psa javascript interactive-chart

A prototype interactive visualization showing how Philippine industries rank by number of employed persons each year. Hover to follow an industry's path, click to pin it, and filter by sector.

Data: Philippine Statistics Authority (PSA) Labor Force Survey, annual figures by major industry group (2009 PSIC), downloaded from PSA OpenSTAT. Extraterritorial organizations and the partial 2026 year are excluded.

This is an independent project and is not an official PSA product.
